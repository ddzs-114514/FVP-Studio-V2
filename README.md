# FVP Studio V2 · 剧本工坊早期版

这是保留当前 GUI 设计的早期版（0.2.1，2026-10-05）。仓库现已公开，包含 GUI 和现有自作 Python 后端、必要资源接口、依赖、空配置及合成测试。**不是全 FVP 游戏全功能完成版，也不包含任何测试游戏。**

直接打开 `web/fvp_story_studio_prototype.html` 仅是静态界面预览；连接 Python 后端须按下面方式启动。页面从空白工程开始，示意图由程序绘制。原作数据与本机绑定由使用者在本地提供，不从仓库下载。

当前开发版已包含章节/场景、时间轴、选项分支轨道、原作素材选择、人物信息、换装/表情预览、文字引言和测试副本生成窗口。

| 功能与目标 | 当前完成情况 | 验证范围 |
|---|---|---|
| 星空 HD 场景输出 | 已实现，用户在独立测试副本中验收 | 用户原作引擎观察 |
| 其他目标的立绘、表情、alpha、XY、Z | 已接入各目标自身原生调用链 | 内存编译与代码检查；逐款实机验收仍需继续 |
| 二维缩放 S2 | 按目标原生能力启用 | hime 没有该原生通道 |
| 世界/hime 能力窗口 | 已连接目标能力与显式文字编码选择 | 内存编译及实际浏览器窗口检查 |
| Happy / 恋曲 | 实际脚本配对或启动程序登记仍需补全 | 尚不能声明完成兼容 |
| 各目标换装渐变、旋转角度、循环/停止 | 继续开发 | 不能仅凭已有 GUI 控件视为原生输出完成 |
| 全目标 CG、镜头、blur、transition、分支及整章 | 继续开发 | 星空已有能力不等于全目标化完成 |
| 文字引言、OP、图片字幕 ED 原生输出 | 未完成 | 文字引言 GUI 已有 |

后端最低 Python 版本为 3.10，依赖 Pillow 和 psutil。独立副本导出使用 Windows 系统 robocopy；部分音频转码另需 FFmpeg（未捆绑）。BIN/HZC 处理接口已随包提供，不再搜索开发者工作区或加载外部 adapter 脚本；没有捆绑来源不明的外部 HCB 解析代码。

`sources.example.json` 是空模板，不含本机登记。正常素材/输出模式需 1～64 项明确来源；空配置仅可用显式的 `--empty-preview` 启动检查，不能生成游戏。

## 启动与本机配置

在仓库根目录运行：

```sh
python -m pip install -r requirements.txt
python -m fvp_studio --sources sources.example.json --empty-preview --port 18826
```

打开 `http://127.0.0.1:18826/fvp_story_studio_prototype.html`。启动器仅监听本机，并创建普通工作根，不会复制或启动游戏。现有 18815/18816 服务无需停止。也可显式指定 `--html`、`--output-root`、`--audio-root`、`--test-root`。

要读取素材或输出，先建立自己的 `sources.local.json`，不用 `--empty-preview`。原作接入位置/指令及 EXE 识别签名不随包分发：相关功能还需私人本机绑定，见 [本机配置说明](examples/local_configuration.md)。缺少或不匹配时明确拒绝，不使用其他目标的规则、不猜测尺寸。**仅克隆仓库和安装 Python 依赖，不代表已配置原生输出。**

普通资源列表、BIN/HZC 读取和空工程接口可以独立使用。尺寸/几何发现需要已审核的本机引擎签名；星空专用输出另需已审核的母本与剧情接入绑定。其他目标仍受上表中的原生能力边界限制。

## 合成检查

检查不读取、复制或启动原作游戏：

```sh
node tests/test_public_preview.cjs
python -I -B tests/test_backend_release.py
```

检查覆盖独立导入/启动、空配置、绑定与身份漂移、原作/工作目录隔离、新副本拒绝覆盖、BIN/HZC 合成处理，以及 GUI 模型。不能替代完整浏览器视觉或各游戏引擎验收。
