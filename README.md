# FVP Studio V2 · 剧本工坊 GUI 预览

这是保留当前 GUI 设计的初始上传版本（2026-10-05）。维护者目前将仓库设为私有；本次包含清理后的 HTML、文档、空白工程、空来源配置和合成测试。必要后端仍在审阅中，未附在此仓库，不应把本版本当成完整可运行的 Studio。

直接打开 `web/fvp_story_studio_prototype.html` 可查看界面；页面从一个空白场景开始。示意图由页面代码绘制，空白示例不含游戏素材或台词。静态预览没有原生后端连接，不能据此生成测试游戏。不要把此候选说明中的“后端未附”理解为开发版没有实现输出。

当前开发版已包含章节/场景、时间轴、选项分支轨道、原作素材选择、人物信息、换装/表情预览、文字引言和测试副本生成窗口。

| 功能与目标 | 当前完成情况 | 验证范围 |
|---|---|---|
| 星空 HD 场景输出 | 已实现，用户在独立测试副本中验收 | 用户原作引擎观察 |
| 其他目标的立绘、表情、alpha、XY、Z | 已接入各目标自身原生调用链 | 内存编译与代码检查；逐款实机验收仍需继续 |
| 二维缩放 S2 | 按目标原生能力启用 | hime 没有该原生通道 |
| 世界/hime 能力窗口 | 已连接目标能力与显式文字编码选择 | 内存编译及实际浏览器窗口检查 |
| Happy / 恋曲 | 实际脚本配对或启动程序登记仍需补全 | 尚不能声明完成兼容 |
| 各目标换装渐变、旋转角度、循环/停止 | 继续开发 | 不能仅凭已有 GUI 控件视为原生输出完成 |
| 全目标 CG、镜头、blur、transition、分支及整章 | 继续开发 | 星空已有能力不等于全目标化完成 |
| 文字引言、OP、图片字幕 ED 原生输出 | 未完成 | 文字引言 GUI 已有 |

后端最低 Python 版本为 3.10。图像解码/构建需要 Pillow，Windows 独立副本导出需 psutil 和系统 robocopy；自定义音频转码可能需要 FFmpeg。部分资源接口还动态加载可选 adapter 脚本，其来源与许可需要独立审阅，当前候选未附。现阶段不要把后端基本依赖列表当作完整安装保证。

`sources.example.json` 是空模板，不包含本机登记。使用后端时需另建私人来源配置；开发版加载器要求 1～64 个真实本机登记，不接受空列表。空模板本身用于说明结构，不能原样作为可用注册运行。

## 本地预览与检查

直接打开上面的 HTML 即可预览界面；无需先安装后端依赖。页面可能提示后端离线，这是当前仅上传 GUI 版本的预期状态。

安装 Node.js 后，可运行无网络、无游戏、无 DOM 初始化的模型检查：

```sh
node tests/test_public_preview.cjs
```

检查覆盖 JavaScript 语法、空工程保存/载入、空来源隔离，以及断开场景跳转和嵌入媒体的拒绝处理；不代表完整浏览器视觉验收或原作引擎兼容性验收。
